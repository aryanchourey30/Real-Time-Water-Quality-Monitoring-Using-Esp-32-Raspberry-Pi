# Real-Time Water Quality Monitoring System

A full-stack smart water monitoring project that combines IoT-ready backend services, community reviews, weather context, and AI-assisted analysis to help users understand water quality in real time.

This repository brings together the engineering side of the project across React, Node.js, MongoDB, Python, and AI integration, with a focus on practical system design rather than a static demo.

## Highlights

- Real-time monitoring flows for water quality data
- ESP32 and Raspberry Pi oriented project context
- AI-assisted summaries and chatbot support
- Community review analysis for location-based insights
- Weather-aware backend endpoints and data enrichment
- Full-stack architecture with a React frontend and Express backend

## Main Application

The primary app lives in:

- `project water main - Final/`

Inside that folder you will find:

- `frontend/` for the React + Vite user interface
- `backend/` for the Express + MongoDB API and AI integrations

## Quick Start

```bash
cd "project water main - Final/backend"
npm install
npm run dev
```

In another terminal:

```bash
cd "project water main - Final/frontend"
npm install
npm run dev
```
